aws: the AWS command line. Agents confirm with the user before anything that creates, changes or deletes cloud resources (AGENTS.md).

aws --version                                 # which version is installed (mise installs it; there is no Homebrew copy to update)
aws configure sso                             # set up a profile that signs in through IAM Identity Center (SSO): the recommended way, no long-lived keys
aws sso login --profile NAME                  # sign in (opens a browser); the session lasts a few hours
export AWS_PROFILE=NAME                       # select that profile for subsequent commands; login alone does not select it
aws sts get-caller-identity                   # who am I? shows the account id and role: the first thing to run when something fails
aws configure list-profiles                   # the profiles in ~/.aws/config
aws configure list                            # which profile, region and credentials are in effect right now, and where each comes from
aws s3 ls                                     # list your buckets; aws s3 ls s3://bucket/prefix/ lists inside one
aws s3 cp file.txt s3://bucket/key            # upload a file; aws s3 cp s3://bucket/key . downloads it
aws s3 sync ./dist s3://bucket/path --dryrun  # preview a folder sync (--dryrun); drop --dryrun to do it
aws s3 sync ./dist s3://bucket/path --delete --dryrun
                                              # --delete also removes remote files missing locally: always dry run first
aws ec2 describe-instances --query 'Reservations[].Instances[].[InstanceId,State.Name]' --output table
                                              # list instances, picking fields with --query (JMESPath) and a table layout
aws lambda list-functions --query 'Functions[].FunctionName' --output text
                                              # just the names, one per line
aws logs tail /aws/lambda/NAME --follow       # follow a CloudWatch log group (like tail -f)
aws cloudformation describe-stacks --stack-name NAME
                                              # details of one stack; most services follow the aws <service> <action> pattern
aws s3 ls --region eu-west-1                  # run against another region (--region); AWS_REGION sets it for the shell
aws ... --output json                         # output formats: json, yaml, text, table (also set in the profile)
aws ... --no-cli-pager                        # do not open a pager for long output (scripts); AWS_PAGER='' does it for the shell
aws ... --debug                               # show the full request log when a call fails in a way you do not understand
aws help ; aws s3 help ; aws s3 cp help       # the built-in manual for any command, subcommand or action
Never put access keys in files inside a repo. Prefer SSO profiles over aws configure with long-lived keys.
Writes (create, update, delete, sync --delete, put-*) change real resources: preview or dry-run first.

AWS skills (optional; use the same AWS_PROFILE; catalog Region is us-east-1):
aws login --profile NAME                      # alternative browser sign-in using AWS console access, when not using SSO
aws agent-toolkit search-skills --search-query serverless --region us-east-1
aws agent-toolkit list-installed-skills       # inspect local toolkit-managed installations
aws agent-toolkit add-skill --skill-name aws-iam --agent universal --region us-east-1
aws agent-toolkit add-skill --skill-name aws-iam --agent claude-code --region us-east-1
aws agent-toolkit check-skill-updates --all --region us-east-1
aws agent-toolkit remove-skill --skill-name launch-with-aws --agent universal
aws agent-toolkit remove-skill --skill-name launch-with-aws --agent claude-code
                                              # only if unwanted: removes the selected local skill from each agent
