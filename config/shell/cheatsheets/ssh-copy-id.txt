ssh-copy-id: install your PUBLIC key on a server so you can log in without typing the password.

ssh-copy-id user@host                         # copy your default public key (asks for the server password once)
ssh-copy-id -i ~/.ssh/id_ed25519.pub user@host
                                              # a specific key: give the .pub file (-i)
ssh-copy-id -p 2222 user@host                 # a different port (-p)
ssh-copy-id -n user@host                      # dry run (-n): show which keys it would add and add nothing
ssh-copy-id -f user@host                      # force (-f): skip the check for keys that are already installed
ssh-copy-id -o ProxyJump=jump@bastion user@host
                                              # pass ssh options (-o), here a jump host
ssh user@host                                 # then test: it should log in without asking for the account password
cat ~/.ssh/id_ed25519.pub | ssh user@host 'cat >> ~/.ssh/authorized_keys'
                                              # the same thing by hand, where ssh-copy-id is missing
It appends the key to ~/.ssh/authorized_keys on the server. No key yet? explain-ssh-keygen.
Only ever copy the .pub file. The file without .pub is your private key and never leaves your machine.
